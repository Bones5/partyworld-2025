# SVG Styling Guide

This document explains how to style SVG icons in the Partyworld 2025 theme.

## Overview

SVG icons in this theme come in two main styles:
- **Filled icons**: Use `fill` for coloring (e.g., star ratings)
- **Outline icons**: Use `stroke` for coloring (e.g., cart, account, search)

## Adding New Icons

1. Add your SVG file to `assets/icons/`
2. Run `npx grunt svgstore` to regenerate the icon sprite
3. Reference the icon in templates using:
   ```html
   <svg><use xlink:href="#icon-svgFileName" /></svg>
   ```

The icon ID is based on the filename with `icon-` prepended (e.g., `cart.svg` becomes `#icon-cart`).

## Icon CSS Classes

### Base Class

All icons should use the `.icon` base class:

```html
<span class="icon">
    <svg><use xlink:href="#icon-example" /></svg>
</span>
```

### Modifier Classes

| Class | Description | Use Case |
|-------|-------------|----------|
| `.icon--outline` | Sets `fill: none` and applies `stroke: currentColor` | Stroke-based icons (cart, account, search) |
| `.icon--ratingEmpty` | Empty star color | Rating stars |
| `.icon--ratingFull` | Filled star color | Rating stars |

### Using the Outline Class

For stroke-based SVG icons, add the `.icon--outline` modifier:

```html
<span class="icon icon--outline">
    <svg><use xlink:href="#icon-cart" /></svg>
</span>
```

This ensures the icon:
- Has no fill (`fill: none`)
- Uses `stroke: currentColor` to inherit the parent's text color
- Has a default stroke width of 2px

## Creating SVG Icons

### Filled Icons

For filled icons, ensure the SVG uses `fill` for coloring:

```xml
<svg viewBox="0 0 24 24">
    <path d="..." />
</svg>
```

### Outline Icons

For outline/stroke-based icons, set up the SVG with stroke attributes:

```xml
<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
    <path d="..." />
</svg>
```

## Best Practices

1. **Use `currentColor`**: This allows icons to inherit color from their parent element
2. **Consistent sizing**: Use the same viewBox dimensions (24x24 recommended) for consistency
3. **Accessibility**: Always provide accessible labels when icons convey meaning:
   ```html
   <span class="icon icon--outline" aria-hidden="true">
       <svg><use xlink:href="#icon-cart" /></svg>
   </span>
   <span class="u-hiddenVisually">Shopping Cart</span>
   ```
4. **Transitions**: The base `.icon` class includes a transition for smooth color changes on hover/focus states

## File Locations

- Icon SVG files: `assets/icons/`
- Icon SCSS styles: `assets/scss/components/citadel/icons/_icons.scss`
- Generated sprite: `assets/img/icon-sprite.svg` (generated by grunt)
