# Partyworld 2025 Theme Map

A visual guide to the template structure and component organization of the Partyworld 2025 BigCommerce Stencil theme.

---

## Theme Architecture Overview

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                              LAYOUT TEMPLATES                                    │
│                           templates/layout/                                      │
├─────────────────────────────────────────────────────────────────────────────────┤
│  ┌─────────────────┐    ┌─────────────────┐                                     │
│  │    base.html    │    │   empty.html    │                                     │
│  │  (Full layout)  │    │  (Minimal/API)  │                                     │
│  └────────┬────────┘    └─────────────────┘                                     │
│           │                                                                      │
│           ▼                                                                      │
│  ┌─────────────────────────────────────────┐                                    │
│  │              PAGE TEMPLATES              │                                    │
│  │            templates/pages/              │                                    │
│  └─────────────────────────────────────────┘                                    │
└─────────────────────────────────────────────────────────────────────────────────┘
```

| `pages/home` | `home.js` | Homepage interactions |

| `pages/product` | `product.js` | PDP functionality |
| `pages/cart` | `cart.js` | Cart interactions |
